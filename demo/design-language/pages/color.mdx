# Color

Kiln's color system has three layers: brand colors (primary and accent), semantic colors (status and severity), and structural neutrals (the gray scale). Each layer has a distinct job, and they are not interchangeable.

## The decisions

**Primary `#89216b` — why this color?**

The primary was chosen for three reasons: it is distinctive enough to be recognizable, warm enough to feel approachable, and dark enough to hit 7.2:1 contrast on white without any adjustment. Most brand colors fail WCAG AA when used for text — primary was specifically selected to pass by default so it can be used for links, focus rings, and interactive affordances without needing a separate "text-safe" variant.

**Accent `#f7b733` — energy with constraint**

The accent provides warmth and visual energy. It is deliberately not used for text or interactive states — it does not have sufficient contrast on white backgrounds for body text. Its job is decorative and highlight-only: gradient stops, loading indicators, hover accents. Treating it as a decoration token rather than a semantic one prevents misuse.

**The gray scale — why Slate, not neutral gray?**

The gray scale uses the Slate family (cool blue-leaning grays) rather than neutral grays. This creates a more refined, modern feel and pairs naturally with the warm primary. The contrast between warm brand and cool neutrals is intentional — it gives the UI visual depth without requiring complex color work from the consumer.

**Status and severity colors — why not themeable?**

Red means error. Green means success. These carry universal semantic meaning that predates any brand. Making them themeable would allow a consumer to set error to purple — technically valid, but cognitively harmful. Status and severity colors are locked.

**The two-surface model**

Light mode uses `#ffffff` for raised surfaces and `#f8fafc` for the page background. Dark mode uses `#0d1525` for raised surfaces and `#0b1120` for the background. Pure black `#000000` was rejected because it creates a harsh contrast jump that feels cheap and is harder on eyes in low-light environments. The deep navy reads as premium and reduces eye strain.

## Usage guidelines

**Do:** Use `--kiln-primary` for links, focus rings, active nav items, and primary actions. Use `--kiln-gray-600` for body text on light surfaces. Use status colors only for their semantic meaning.

**Don't:** Use `--kiln-accent` for text — it does not meet contrast requirements on white. Don't use status red for non-error UI (e.g. a "delete" CTA that isn't destructive yet). Don't add new colors — use the token system.

## Extending it

Primary and accent can be overridden via the theming system (`registerTheme`, `applyTheme`). The theming engine automatically recalculates all derived palette values and enforces WCAG AA compliance. Status and severity colors are not themeable. Gray scale is not themeable — it is a structural neutral, not a brand expression.
