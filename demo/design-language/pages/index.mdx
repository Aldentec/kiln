# Design Language

Great UI is not about decoration — it is about removing friction. Every color decision, every spacing step, every easing curve in Kiln exists to help users understand, navigate, and trust the interface they're using. A design language is the agreement between the system and the person building with it: predictable, internally consistent, and honest about the tradeoffs it has made.

This documentation captures those agreements. It is not exhaustive — it is opinionated. Kiln makes choices so you don't have to relitigate them for every project.

## What's documented here

Kiln's design language covers the foundation layer that every component is built on: color, typography, spacing, elevation, motion, border radius, theming, and iconography. Each section explains what the system is, why specific choices were made (this is the important part), and how to work with or extend it safely.
