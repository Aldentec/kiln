# Typography

Kiln uses two typefaces: Space Grotesk for all interface text, and JetBrains Mono for code. Everything else — the scale, the line heights, the tracking — is derived from first principles about readability and hierarchy.

## The decisions

**Why Space Grotesk?**

Space Grotesk has geometric construction with humanist details. The letterforms are clean and modern without feeling cold or overly technical — the slightly quirky details (the open `a`, the distinctive `t`) make it readable at small sizes while giving it personality at display sizes. It reads as "technical product" rather than "corporate", which matches Kiln's intended audience: developers and technical product teams who build real things.

**Why JetBrains Mono?**

JetBrains Mono was designed specifically for code editors, which means it has been optimised for the exact use case Kiln needs: dense monospaced text at small sizes with maximum legibility. Its ligature support (→, !=, >=) makes code easier to scan. It is distinct enough from Space Grotesk that code blocks are immediately recognizable as code without needing a box or background.

**The type scale — why these specific sizes?**

The scale is not linear. The jumps between sizes are deliberate: `xs → sm` is a small step for fine-tuning labels, but `2xl → 3xl → 4xl` are large jumps that force real hierarchy decisions. There is no `1.375rem` size — if you need something between `lg` and `xl`, you are probably trying to split a difference that shouldn't be split. Pick the larger one.

**72ch max-width on body text**

Optimal line length for reading is 50–75 characters. At 16px with Space Grotesk's average character width, 72ch hits roughly 65–70 characters per line — the sweet spot for sustained reading. This is enforced on the `p` element in the MDX provider and should be applied to any long-form body copy.

**Why `1.625` line height for body?**

`leading-tight` (1.25) is for headings, where density communicates importance and blocks of text are short. Body copy needs air — `leading-relaxed` (1.625) reduces eye fatigue during sustained reading. The difference is significant at 16px: `1.5` feels slightly cramped, `1.625` breathes without wasting space.

## Usage guidelines

**Do:** Use `text-base` and `leading-relaxed` for any body copy longer than two sentences. Use `tracking-tight` on headings `2xl` and above — large text looks better slightly tighter. Use `font-mono` for all code, token names, keyboard shortcuts, and technical values.

**Don't:** Use sizes below `text-xs` (12px) anywhere. Don't use `text-4xl` for anything other than display headings or hero sections — it loses legibility as body. Don't mix fonts for decorative effect — Space Grotesk and JetBrains Mono are the only two typefaces in the system.

## Extending it

`--kiln-font-sans` and `--kiln-font-mono` are CSS custom properties and can be overridden with any typeface. Be aware that x-height mismatches between replacement fonts and Space Grotesk will affect spacing rhythm — components use these tokens for both size and line-height calculations, so a font with an unusually tall or short x-height will push things slightly off. Test at several sizes when switching fonts.
